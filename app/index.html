Sehgal Hero App

Download the Android app

  1. Tap the red button. The file SehgalHero.apk downloads.
  2. Open it from the notification (or Files → Downloads).
  3. If the phone says "not allowed", tap Settings → turn on "Allow from this source" → go back.
  4. Tap Install, then Open. Log in once with your Employee No. and password.
  5. If "Play Protect" warns about an unknown app: tap More details → Install anyway. The app is from Sehgal Autoriders, not the Play Store, so Google shows this once.

Updates to the screens come by themselves — you do not reinstall for every change. Remove the old Chrome shortcut from the home screen after the app works.

Download for Windows

  1. Click the red button. SehgalHero-Setup.msi downloads.
  2. Open it. If Windows shows "Windows protected your PC", click More info → Run anyway. No administrator password is needed.
  3. Start "Sehgal Hero" from the desktop icon or the Start menu.
  1. Open this link in Safari or Chrome on the iPhone: sehgalautoriders.github.io
  2. Tap the Share button (square with an arrow; in Chrome it is at the top right).
  3. Tap "Add to Home Screen", then Add.
  4. Always open Sehgal Hero from that home-screen icon — not from the browser.

Opening from the icon keeps you logged in and keeps your saved vehicles on the phone. An iPhone clears a website's saved data if it is only opened in the browser and not used for 7 days.
